# 📋 AI Context — The Knowledge Base

> **Purpose:** This folder saves the full AI working context so that new AI
> sessions pick up exactly where we left off — without re-analyzing
> the codebase, reviewer comments, or experiment results.
>
> This directory acts as the "brain" of the project and is explicitly enforced by `.agents/AGENTS.md`.

## Files Index

| File | What it contains |
|------|-----------------|
| `STATUS.md` | **Start here.** Current state: what's done, what's missing, next steps. |
| `TASKS.md` | Checklist of all high-level tasks and phases. |
| `IMPLEMENTATION_ROADMAP.md` | Granular, step-by-step checklist for the *current* active task. |
| `PROJECT_MAP.md` | Complete map of all files, folders, and key functions. |
| `CODE_CHANGES.md` | Every code change made, with rationale. |
| `EXPERIMENT_RESULTS.md` | Baseline tables, GSM run paths, metrics. |
| `REVIEWER_MAP.md` | Map of reviewer concerns → code fixes → manuscript sections. |
| `AI_MEMORY.md` | User-specific preferences, workflow quirks, and strict negative constraints. |
| `DOCX_MANIPULATION.md` | Custom protocols for docx file handling and formatting. |
| `copilot-instructions.md` | Coding conventions and AI agent rules. |

## Related rules (Workspace Rules)
AI behaviors are strictly governed by `.agents/AGENTS.md`.
